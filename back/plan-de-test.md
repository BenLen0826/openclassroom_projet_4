# Plan de test du back — correspondance avec les tests réalisés

Objectif : **80 % de couverture minimum** pour tous les indicateurs (instructions, branches, lignes, méthodes, classes, complexité).

Notation des tests : `Classe#méthode`
- **(U)** test unitaire : la classe est testée seule, ses dépendances sont mockées avec Mockito ;
- **(I)** test d'intégration : l'application complète est démarrée, avec une requête HTTP (MockMvc), un vrai token JWT et une base H2.

Certains exemples du plan concernent l'**affichage**, qui est le rôle du front : boutons visibles pour un admin, déconnexion.
Pour ces lignes, la colonne « Tests » indique ce que le back fournit et vérifie pour rendre ce comportement possible.
